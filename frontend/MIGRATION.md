# 功能迁移核对

所有页面使用 Vue 3 响应式组件渲染；参考旧版 `reference/admin.original.html` 的接口和操作契约，保留现有服务数据格式。页面模型列表来自服务端，不在生产代码中写入模拟模型或用量。

| 页面 | 保留的主要能力 |
| --- | --- |
| 服务概览 | 服务状态、账号/余额/请求/用量指标、趋势、最近请求、连接地址与密钥复制、连通测试、积分包到期提醒、详细数据 |
| 账号管理 | 国内/国际授权登录与二维码轮询、默认/临时切换与还原、别名备注、移除、凭证刷新、积分包查询、签到、观察池检查与释放、自动轮换、服务设置、账号×模型体检 |
| 任务中心 | 账号选择、任务列表、接受、领取、自动执行、新手课堂、每日批量操作、服务端队列进度 |
| 每日签到 | 全部签到、今日状态、各账号结果、连续天数与额度、签到时间设置 |
| 用量分析 | 今日/昨日/自然周/月/指定日期、账号/平台/模型筛选、请求/Token/积分指标、小时及日趋势、多模型曲线、排行、账号与模型交叉明细、体检结果、CSV 导出 |
| 请求日志 | SSE 实时流、冻结/恢复、账号与模型过滤、错误过滤、明细、CSV、清空本地日志、服务器事件 |
| 模型广场 | 原生/聚合目录、更新、平台与品牌筛选、搜索、真实倍率标签、复制模型 ID、curl/Python/Node 调用示例、五个指定模型厂商的 SVG 标识 |
| API 密钥 | 创建、一次性显示完整密钥、编辑、启停、删除、每日请求/Token/积分限额、账号与模型白名单 |
| 多反代聚合 | 自定义/OpenCode/Trae/Qoder 配置、模型前缀和映射、API Key/PAT/refreshToken、Trae 登录链接、模型探测、逐个/批量测试、额度、健康状态、启停、清除冷却、删除 |
| 备份恢复 | 下载、选择 JSON 并预览、确认恢复、自动备份设置、立即执行、备份记录 |

备份文件的实际范围沿用后端：账号、当前账号、用量统计及签到状态。页面不宣称它包含所有反代配置和密钥。

小时统计未采集区间用空缺表示，不补成 0；自然周从周一开始，原后台滚动七日汇总单独保留。后台失败时显示明确错误并保留上次同步数据。危险操作使用确认弹窗，密钥创建期间阻止误关弹窗。

## 验证边界

自动浏览器测试通过隔离模拟 API 核对交互、请求方法和字段，并检查空数据、失败、授权成功流程、无 Emoji、无横向溢出及日夜主题。另以真实 `server.js` 的隔离实例验证管理鉴权、管理台发布内容和 OpenCode key 的省略/显式删除语义。

本次没有使用用户的真实账号发起上游登录、签到、任务领奖、收费聊天或恢复备份。上述操作的真实上游响应、服务器已有数据量和最终部署环境仍需在用户部署环境核对。演示服务及截图中的所有业务数字都是测试数据。
